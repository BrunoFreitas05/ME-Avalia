ME Avalia — Política de Privacidade

Extensão Chrome · Melhor Envio · Octadesk

1. Visão Geral

Esta Política de Privacidade descreve como a extensão ME Avalia coleta, utiliza e armazena informações durante o seu uso. O ME Avalia foi desenvolvido para uso interno da equipe de suporte da Melhor Envio e opera exclusivamente dentro da plataforma Octadesk.

Última atualização: julho de 2026

2. Dados Coletados pela Extensão

Durante o uso, a extensão coleta e utiliza as seguintes informações:

  • Nome e e-mail da conta Google do agente: obtidos via a API chrome.identity do navegador, com a finalidade exclusiva de identificar o colaborador nos relatórios de uso interno da equipe. Nenhuma senha ou dado de autenticação Google é acessado.
  • Token de autenticação do Octadesk: capturado automaticamente a partir dos cabeçalhos das requisições feitas pelo navegador ao acessar o Octadesk. Utilizado exclusivamente para autenticar as chamadas à API do Octadesk durante a sessão.
  • Tickets selecionados na lista: números e identificadores dos tickets que o agente seleciona manualmente na interface do Octadesk antes de acionar a extensão.
  • Mensagem pública: texto digitado pelo agente no editor da extensão, salvo localmente para facilitar o reuso em sessões futuras.
  • Dados de uso por sessão: ao final de cada sessão, são registrados: data, hora, tickets processados, pesquisas enviadas, tickets que atingiram o limite de 3 envios e erros ocorridos. Esses dados são enviados para uma planilha interna de controle da equipe.
Informação de identificação pessoal: a extensão coleta nome e e-mail da conta Google do agente para fins de identificação nos relatórios internos de uso da ferramenta.

3. Como os Dados São Armazenados

Os dados de sessão (nome, e-mail, métricas de uso) são enviados ao final de cada execução para uma planilha Google Sheets de uso interno da Melhor Envio, acessível apenas pelo administrador da extensão. Os demais dados (mensagem salva, token, progresso) ficam armazenados exclusivamente no dispositivo do usuário via chrome.storage.local.

O token de autenticação do Octadesk é armazenado temporariamente por até 4 horas e descartado automaticamente após esse período. A mensagem salva e o progresso de sessão permanecem no armazenamento local até que o usuário os limpe ou desinstale a extensão.

4. Finalidade dos Dados Coletados

  • Nome e e-mail Google: identificar o agente nos relatórios internos de uso da ferramenta — quantidade de sessões, pesquisas enviadas, erros, etc.
  • Token Octadesk: autenticar as chamadas à API do Octadesk para envio de mensagens e pesquisas de satisfação.
  • Dados de sessão: gerar relatórios internos de uso para gestão da equipe de suporte.

Nenhum dado é utilizado para fins publicitários, de marketing ou compartilhado com terceiros fora do ambiente interno da Melhor Envio.

5. Compartilhamento de Dados

Os dados coletados são utilizados exclusivamente para uso interno da Melhor Envio. A extensão não vende, não transfere e não compartilha nenhuma informação com terceiros fora dos seguintes destinos:

  • API do Octadesk (*.prod.octadesk.services) — para envio de mensagens e pesquisas de satisfação, que é a função principal da extensão.
  • Planilha interna Google Sheets — para registro dos dados de uso por sessão, acessível apenas pelo administrador da equipe.

6. Domínios Acessados

  • app.octadesk.com — interface web do Octadesk, onde a extensão lê os tickets selecionados pelo agente.
  • *.prod.octadesk.services — API oficial do Octadesk, utilizada para enviar mensagens e pesquisas de satisfação.
  • brunofreitas05.github.io — configurações remotas da extensão (mensagem padrão e flag de edição).
  • script.google.com / script.googleusercontent.com — envio dos dados de uso da sessão para a planilha interna.

Nenhum outro site ou serviço é acessado pela extensão.

7. Permissões Utilizadas

  • identity: para obter o nome e e-mail da conta Google do agente, usados nos relatórios internos de uso.
  • storage: para salvar a mensagem e o progresso da sessão localmente no dispositivo.
  • notifications: para exibir uma notificação ao final de cada sessão de envio.
  • webRequest: para capturar o token de autenticação dos cabeçalhos das requisições ao Octadesk.
  • scripting: para injetar o script de leitura de tickets na página do Octadesk.
  • tabs: para identificar a aba ativa do Octadesk.
  • alarms: para manter o processamento ativo em background durante sessões longas.
  • webNavigation: para detectar quando a página do Octadesk terminou de carregar.

8. Uso por Menores

Esta extensão é destinada exclusivamente ao uso profissional por agentes de suporte da Melhor Envio. Não é direcionada nem adequada para uso por menores de idade.
